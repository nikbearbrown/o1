# Measuring the Struggle: Process Friction Traces as Independent Evidence of Genuine Learning in the Age of Generative AI

## Executive summary

**About.** If a generative model can produce the artifact (essay, exam, project), the artifact no longer proves learning happened. The paper proposes measuring the process instead: seven observable "friction" components (temporal engagement, error trajectory, cross-context transfer, uncertainty calibration, social knowledge texture, retrieval decay, scaffolding response) combined into a Genuine Learning Probability (GLP) score, positioned as a second evidence stream and not a replacement for artifact assessment.

**Status.** Full prose, 4,722 words, headed "Preprint". I found no study results in it: it is a framework with proposed models, an ensemble design, and an ethics section on observation versus surveillance. I did not check whether it has been posted anywhere. It is not in the CV's preprint list.

**Blocks.** No empirical test of GLP exists in what I read. The "gaming costs as much as doing the work" claim is argued, not measured.
