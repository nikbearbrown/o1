# Evaluating Tools for AI in Education: A Structured Framework

## Executive summary

**About.** Proposes criteria for judging educational AI tools (LLMs, prompt engineering, bots and "bot gardens", vector databases, LangChain and LangFlow, no-code chatbot creation, fine-tuning custom LLMs, cloud agnosticism and performance).

**Status.** Draft, 7,069 words, four co-authors besides Bear (names in the draft). Framework only as far as I read; I did not see the framework applied to real tools or tested with educators.

**Blocks.** The tool landscape is probably dated (the AI4ED repo's first commit is 2024-02-17) and needs a refresh. No validation of the criteria. Co-author agreement and author order are not recorded.

**Next.** Apply the criteria to a small set of current tools and report where raters disagree; that is the evidence the paper currently lacks.
