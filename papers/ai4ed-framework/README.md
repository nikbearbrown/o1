# The AI4ED Framework for Building Educational AI Tools

## Executive summary

**About.** After a literature review, a twelve-step heuristic framework for building educational tools on LLMs and chatbots, aimed at educators and developers: personalized, efficient, broadly accessible.

**Status.** Draft marked DRAFT, 7,112 words, with a reference list, two co-authors besides Bear (names in the draft). The three AI4ED papers are siblings: this is the building framework, the other two cover trust and tool evaluation.

**Blocks.** The framework is argued from literature; I found no test of it with a real tool built by following it. I did not check how recent the literature is.

**Next.** Build one tool by following the twelve steps and report what the steps got wrong; fold the three AI4ED papers into one if the overlap is large.
