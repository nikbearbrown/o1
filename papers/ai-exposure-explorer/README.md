# What the Abilities Cannot See: An Occupation Explorer for the Human Layer of AI Exposure

## Executive summary

**About.** A paper about the live AI Exposure Explorer (irreducibly.xyz/onet): what it shows (BLS employment indexed to 2018 against AI milestones, plus 52 O*NET Abilities per occupation), what the Abilities data cannot show, and a pre-specified version 2 that adds the missing "decision weight" layer from data the project already holds.

**Status.** Draft 0.1 dated 2026-10-24, 2,246 words, written by CRITIQ in silent mode. The only finding so far is one occupation pair (Graphic Designers vs Carpenters) from a read-only audit on 2026-08-14, 8 raters per occupation: Skills descriptors do not separate the pair, Work Context descriptors separate it sharply and against the intuitive story. That is an audit, not a result.

**Blocks (from the draft's own status box).** No per-ability AI-tier map verified; the employment-weighted ability-demand pipeline and CSV were not located; the AIOE comparison needs a SOC crosswalk and its repository has no licence file. No literature search has been done.

**Next.** Decide authors (the draft credits the tool's builders), then close the blocks above before any claim is made.
