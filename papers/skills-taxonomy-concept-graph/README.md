# A Typed, Versioned Concept Graph for Skills: Linking Courses, Job Postings and Learners Without Collapsing Distinctions

## Executive summary

**About.** A design-and-evaluation-plan paper (registered-report shape) for the SEIS skills taxonomy: skill concepts with immutable IDs, types, scoped aliases and broader/narrower edges, so syllabi, postings and student evidence can be compared without merging things that are only related (Swift, Oracle, Apache; PHP 7; Ajax filed as a language).

**Status.** Draft 0.1 dated 2026-10-24, 2,101 words. Measured state at that date: 4,274 legacy tag rows kept, 81 proposed concepts, none reviewed, 3 with a relation, 0 mapped to an external standard (ESCO, O*NET, SFIA). No results; the findings section is a plan.

**Blocks.** The hierarchy, evaluation thresholds, reviewers and authors are not locked. No prior-art check against ESCO, O*NET technology skills or Lightcast has been done.

**Next.** Decide whether this and `../skills-lexicon/` are one paper or two. They overlap: the lexicon is the working implementation of the same idea, with a different relation set and a per-claim evidence model.
