# Papers: index

## Executive summary

**What this is.** Every paper, started or possible, found by searching all of `books/` on 2026-10-28. 24 folders, one per paper, each with a README. Status and blockers are the honest ones, taken from the draft's own markers where it has them (TO DO counts, status boxes) and from reading the abstract and structure otherwise. I did not read every draft end to end, and no citation was checked.

**Where to start.** Three groups are closest to the AI-and-jobs research: the Irreducibly Human line (7 folders), the jobs.humanitarians.ai and ai-jobs line (5), and the provenance line (3: NanoLex, Facts System, figure validation). They share one idea: a claim is only as good as its recorded evidence, and a model's say-so is not evidence.

Source paths in each README are relative to the `books/` folder of the author's private working tree (`bear-textbooks`), which is not part of this repository. They are pointers, not links.
