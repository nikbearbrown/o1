# Books: find one to co-author

## Executive summary

**What this is.** A list of the books in the `nikbearbrown` GitHub account that are open for co-authors: 108 public books, each with a title, a short description and a link to the repository where the work happens. If you want to co-author one and help get it published, open its repository, read its README, and propose what you would write or fix.

**How to join.** Open an issue or a pull request on the book's repository. Check the repository's licence first; licences vary by book.

**How current it is.** Built on 2026-10-28 from the live repositories. Most books are drafts of different ages; "commits" and "last push" show how much work each has had. 47 entries have no written description in their repository yet, so the description lists the number of chapters and the first few chapter titles instead.

**Duplicates removed.** Many repositories are copies or renamed variants of the same book (for example a "-with-llms" copy, a "bundle", or a "-fry" backup). Each book appears once, using the most developed public repository. The same book may exist under other names.

**Private books.** Only public repositories are listed. Books kept in private repositories are not shown here.
